# Zigi-Zagi: Feed Barys

A mobile-first browser puzzle game celebrating Kazakhstan's Independence Day. Help the snow leopard Barys catch an illustrated Zigi Cola Independence Day can. Kazakh is the default language, with a Russian language switch. An original synthesized cinematic score and game effects start after the player begins.

## Play locally

Open dist/index.html in a browser, or serve the dist directory with any static HTTP server. The game has no build step or runtime dependencies.

## Included

- 30 levels across three flavor chapters
- Swipe-to-cut rope controls for touch and mouse
- Pendulum motion, stars, spring platforms, moving platforms, bubbles, wind assist, retries, and saved level progress
- Three original vector can illustrations inspired by the supplied product photos
- An original snow leopard mascot, Barys, with a catch-and-celebrate victory animation
- Responsive phone layout, touch-friendly controls, and reduced-motion support
- Original in-browser music and sound effects with a single mute control
- The linked Zigi-Zagi logo in the header
